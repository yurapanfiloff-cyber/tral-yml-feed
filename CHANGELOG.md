# История изменений

## 1.2.1 — 27.07.2026

- автоматическое обновление изменено с одного запуска каждые три часа на один запуск в сутки;
- GitHub Actions запускается ежедневно в 02:17 UTC (05:17 МСК);
- сохранён ручной запуск сразу после изменения цен или ассортимента;
- резервный systemd-таймер для VPS также переведён на ежедневное расписание.

## 1.2.0 — 27.07.2026

- добавлена конфигурация `config.github.json` для запуска без VPS;
- добавлен workflow GitHub Actions с автоматическим запуском по расписанию;
- добавлена публикация только успешно проверенного фида через GitHub Pages;
- перед генерацией загружается предыдущий рабочий фид для сравнения количества оферов;
- при ошибке развёртывание не выполняется и прежняя версия Pages сохраняется;
- отчёт, статус и журнал каждого запуска сохраняются в артефакте на 30 дней;
- добавлен ручной запуск с параметром `force_publish`;
- подготовлены `CNAME`, `.nojekyll` и служебная страница для `feed.tral-diler.ru`.

## 1.1.0 — 20.07.2026

- товары без подтверждённой цены исключаются из YML, но не блокируют публикацию остальных оферов;
- исключённые товары сохраняются в отчёте с URL, названием и причиной;
- товары без заводского индекса модели формируются как упрощённые оферы без `type="vendor.model"`, `<typePrefix>`, `<vendor>` и `<model>`;
- `<name>` упрощённого офера собирается из типа техники, бренда и основных характеристик;
- добавлено сравнение количества оферов с предыдущим рабочим фидом;
- уменьшение до 20% публикуется с предупреждением, свыше 20% блокирует замену;
- добавлено ручное подтверждение `--force-publish`;
- отчёт разделяет критические ошибки, предупреждения и исключённые товары;
- добавлены автоматические проверки новой логики.

Контрольный прогон: 92 карточки, 78 опубликованных оферов, 14 исключений без цены, 2 упрощённых офера, 0 критических ошибок.
